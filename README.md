### 📌 Featured Projects
- **[Explainable Leaf Disease Classifier](https://github.com/grace-mcmahon/explainable-leaf-classifier)** — CNN-based plant disease classifier (99% test accuracy) with Grad-CAM explainability to visualise and critically evaluate the model's reasoning on correct *and* incorrect predictions. Built with PyTorch, ResNet18 transfer learning.
-  **[Password Strength Visualiser](https://github.com/grace-mcmahon/password-strength-visualiser.git)** — A password strength and breach-check tool that explains its reasoning in plain language rather than just a bar. Built with Next.js, React, and TypeScript, with real breach-checking via the Have I Been Pwned API using k-anonymity.
